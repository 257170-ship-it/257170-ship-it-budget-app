# V2 實作與驗證狀態

## 已完成的程式

- 動態預算項目、固定ID、複製、排序、停用、群組與子計畫。
- 申請／核定／調整額、整數分、節與小時分離、指定基礎百分比估算。
- 來源規則確認、比例／單價／流用檢查、調整版本與防止父子加總。
- 九案草稿含原表名稱、金額、採購明細、零額停用列、來源與疑義。
- 支出分攤、代墊、付款、核銷、來源日期與付款日期分離。
- 每週課表預覽、逐堂請假／補課、停課與冪等結算。
- 八張Excel工作表、年度／學年度及計畫、子計畫、項目、日期與狀態篩選。
- 舊資料冪等遷移、原始備份與逐案核對，未知核定／付款／核銷保持待確認。
- Apps Script逐筆版本列、Journal提交可見性、鎖內版本比對、requestId去重。
- 後端Google Workspace同網域白名單角色、私有Drive附件、失敗恢復。
- GitHub Pages新版預覽入口與可使用原API的舊版相容入口。

## 本機驗證

53項自動測試通過：舊版相容15項、後端服務替身10項、新版RPC客戶端3項、資料模型／範本／遷移／Excel25項。TypeScript與正式建置通過。
瀏覽器驗證範本匯入、核定空白、新增計畫與動態項目、請假扣除、代墊狀態及報表。手機375px可用寬度下頁面沒有整體水平溢出，表格在自己的區域橫向捲動。

## 尚未完成的外部部署

- 尚未取得Apps Script專案原始碼／編輯／部署權限，不能把新後端推送進使用者Google帳號。
- 尚未在真實Google獨立測試試算表驗證；後端測試是記憶體Google服務替身，已測中斷、併發鎖、版本衝突、權限、附件與重試。
- 新版安全後端及Google登入的實際整合尚待擁有者部署測試套件。個人Gmail／跨網域OIDC不在此版支援範圍，取得不到Session email一律拒絕。
- 正式資料沒有遷移，沒有停用舊API，也沒有修改其權限。舊版API維持原有存取方式。
- 真正的正式切換仍需原始備份、測試結果、來源hash、停用舊寫入及使用者明確確認；本輪沒有執行。
